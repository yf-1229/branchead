Denkox Linux

日本の教育現場のための Debian ベース Linux。Chromebook と旧型 PC を、軽く、日本語で、安全に。

Period
2026 —
Role
企画 / ビルド / 検証
Status
公開リポジトリ
Stack
Debian, live-build, Xfce

Challenge

学校で使われる端末は Chromebook、旧型 Windows PC、持ち込みのノート PC とさまざまです。日本語入力、教育アプリ、ネットワーク分離、アップデートを最初から整えた状態で配るには、通常の Linux では設定の手間が大きすぎました。

Approach

Debian の live-build で Lite / Standard / Full の3種類を構成。Xfce 4.20、fcitx5 + Mozc、LibreOffice / GCompris / Stellarium / Anki を収録し、Chromebook のタッチパッド・音声・電源管理を自動設定します。アプリとデスクトップを bwrap + OverlayFS で分離する denkox-sandbox と、専用の GRUB テーマも組み込みました。

Outcome

Lite は約 1.2GB、4GB RAM で動作する構成。3つの variants とビルド手順、ISO の構成を公開しています。Chromebook と旧型 PC の両方を、同じ日本語環境で使えるところまでまとめました。

3variants
1.2GBLite ISO
4GB最小 RAM

Stack

  • live-build
  • Xfce 4.20
  • fcitx5 + Mozc
  • bwrap

Telliyaki

Tello ドローンを、ブロックを並べて飛ばす。子ども向けの日本語 Android アプリ。

Period
2026 —
Role
Android / UI / 通信
Status
ベータ
Stack
Kotlin, Compose, UDP

Challenge

子どもがドローンの動きを視覚的に組み立て、実行する前に結果を想像できること。さらに、Tello との通信状態や映像を、アプリを切り替えずに扱える必要がありました。

Approach

UI は 100% Jetpack Compose。基本操作 / 移動 / 回転 / 待機 / アクロ / くりかえしの6カテゴリのブロックを用意し、repeat のネスト、プログラムの保存、未保存の警告、プレビュー、実行、RC 操縦までを1つのアプリにまとめました。Tello へは UDP でコマンドを送り、映像ストリームをアプリ内で受信します。

Outcome

ブロックエディタからプレビュー、実行、RC までを一通り操作できる Android アプリとしてベータ公開。子ども向けの日本語 UI と、通信・映像の状態表示を両立させています。

Obserk

ペンを持っている時間だけを、勉強時間として記録する。カメラと TFLite で集中を可視化する Android アプリ。

Period
2026.01
Role
Android / ML / UI
Status
アーカイブ
Stack
Kotlin, Compose, TFLite

Challenge

タイマーを回すだけでは、実際に集中していた時間は分かりません。ペンを持っているかどうかを端末内で判定し、記録が途切れた時間も含めて扱う必要がありました。

Approach

カメラ映像を TFLite のペン保持判定モデルに渡し、ペンが検出されている間だけ記録。Foreground service で記録を継続し、Room に学習ログを保存します。記録時間と中断時間から効率 (%) を算出し、グラフで表示。UI は Compose で構成しました。

Outcome

ペン検出による記録の継続 / 中断、効率の可視化、学習ログの編集を実装。リポジトリはアーカイブとして公開しています。

%efficiency
ROOMstudy logs

  • Camera
  • Foreground service
